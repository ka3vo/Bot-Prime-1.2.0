# 🤖 Bot Prime — Documentation des commandes

Bienvenue dans la documentation officielle des commandes de **Bot Prime**.

Cette page présente les commandes communiquées pour le bot, organisées par catégorie afin de faciliter leur utilisation.

> Certaines commandes peuvent nécessiter des permissions spécifiques ou être réservées au staff.

## 🛡️ Modération

| Commande | Description |
|---|---|
| `.ban @membre [raison]` | Bannit un membre du serveur. |
| `.unban <ID>` | Débannit un utilisateur à partir de son ID. |
| `.bl @membre/ID [raison]` | Ajoute un membre à la liste de blocage du bot. |
| `.unbl @membre/ID` | Retire un membre de la liste de blocage. |
| `.unblall` | Retire tous les utilisateurs de la liste de blocage. |
| `.clear <nombre\|all>` | Supprime un nombre de messages ou utilise `all` pour le mode prévu par la commande. |
| `.lock [raison]` | Verrouille le salon actuel. |
| `.unlock` | Déverrouille le salon actuel. |
| `.slowmode <secondes>` | Configure le mode lent. `0` le désactive ; maximum : `21600` secondes (6 heures). |
| `.autorole @role` | Configure le rôle automatique. |
| `.autorole off` | Désactive le rôle automatique. |
| `.configticket` | Ouvre ou lance la configuration des tickets. |
| `.reactionrole <idMessage> <emoji> @role` | Associe un rôle à une réaction sur un message. |
| `.setuplogs` | Configure les journaux du serveur, selon la configuration prévue par le bot. |
| `.trap #salon` | Configure le salon utilisé par la commande `trap`. |
| `.trap off` | Désactive la configuration de `trap`. |

## 🎫 Tickets

| Commande | Description |
|---|---|
| `.ticket [type]` | Ouvre un ticket privé avec le staff. |
| `.close` | Ferme le ticket en cours. |
| `.ticketpanel` | Affiche ou configure le panneau de tickets, selon son fonctionnement dans le bot. |

## 💬 Commandes générales

| Commande | Description |
|---|---|
| `Aide` | Affiche la liste des commandes disponibles. |
| `.ghostping @membre` | Utilise la fonction ghostping sur un membre. |
| `.ghostping @role` | Utilise la fonction ghostping sur un rôle. |
| `.ghostping everyone` | Utilise la fonction ghostping avec `everyone`. |
| `.ghostping here` | Utilise la fonction ghostping avec `here`. |
| `.say <texte>` | Envoie le texte indiqué par l'intermédiaire du bot. |

## 📌 Informations importantes

- Remplace les paramètres entre chevrons par les valeurs demandées.
- Les paramètres entre crochets sont facultatifs lorsque la commande les accepte.
- Certaines commandes peuvent nécessiter des permissions particulières.
- Les commandes de modération doivent être utilisées de manière responsable.
- Le fonctionnement exact de chaque commande dépend de son implémentation dans le code source.
