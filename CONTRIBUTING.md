# 🤝 Bot Prime — Guide de contribution

Merci de t'intéresser à **Bot Prime** !

Ce document explique comment proposer des améliorations, signaler des problèmes et contribuer au développement du projet.

## 📌 1. Avant de contribuer

Avant de proposer une modification :

- Consulte le dépôt GitHub pour comprendre le projet.
- Vérifie si le problème ou la suggestion a déjà été signalé.
- Assure-toi que ta proposition concerne réellement Bot Prime.

## 🐛 2. Signaler un bug

Si tu rencontres un problème :

1. Décris clairement le comportement observé.
2. Explique les étapes permettant de reproduire le problème.
3. Indique le résultat attendu.
4. Ajoute les messages d'erreur utiles, si disponibles.
5. Ne partage jamais de token, de mot de passe ou d'autres informations confidentielles.

Tu peux également rejoindre le serveur Discord officiel pour demander de l'aide.

👉 https://discord.gg/THvPPfF8A5

## 💡 3. Proposer une amélioration

Pour proposer une nouvelle idée :

- Présente le problème que ton idée permettrait de résoudre.
- Explique le fonctionnement souhaité.
- Précise les avantages pour les utilisateurs.
- Attends qu'un responsable du projet examine la proposition.

Une suggestion ne garantit pas que la fonctionnalité sera ajoutée.

## 💻 4. Proposer une modification du code

Si tu es autorisé à contribuer au code :

1. Travaille sur une branche séparée.
2. Effectue une modification claire et ciblée.
3. Vérifie que ton changement ne provoque pas de régression connue.
4. Décris précisément les modifications réalisées.
5. Propose ta modification pour examen avant son intégration.

N'ajoute jamais de secrets, de tokens ou de fichiers de configuration sensibles au dépôt.

## 🔐 5. Sécurité et confidentialité

- Ne publie pas de vulnérabilité exploitable en exposant inutilement les utilisateurs.
- Ne partage aucune donnée privée.
- Signale les problèmes de sécurité de manière responsable au mainteneur du projet.

## 📋 6. Examen des contributions

Les contributions peuvent être acceptées, modifiées ou refusées selon leur pertinence, leur qualité et les objectifs du projet.

L'intégration d'une modification reste soumise à l'approbation des responsables du dépôt.
