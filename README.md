# 🤖 Bot Prime

**Bot Prime — Un bot Discord conçu pour simplifier la gestion de vos serveurs.**

Développé par **stormyxx**, avec la participation de **theblack.moon**.

## 📌 Présentation

Bot Prime est un bot Discord qui propose plusieurs fonctionnalités pour faciliter la gestion et l'animation de votre communauté.

## ⚙️ Fonctionnalités

- 🔨 Modération du serveur
- 🎫 Gestion des tickets
- 🎭 Rôles par réaction
- 🎉 Giveaways
- 🛠️ Configuration et outils pour les serveurs
